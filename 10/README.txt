Proyecto Maven para NetBeans (JDK 21). Abra la carpeta que contiene pom.xml como proyecto existente.
SensorIndustrial es abstracta; SensorHumedad, SensorPresion y SensorTemperatura heredan de ella.
SensorTemperatura implementa NotificableAlarma. SensorPresion contiene un CalibradorDigital.
Ejecute com.mycompany.sensorindustrial.SensorIndustrialApp para ver una demostración.
